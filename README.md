# Track Your Gym — Telegram-бот для тренировок

aiogram 3 + SQLite. Программа тренировок с картинками, замена упражнений, полная замена дня.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env          # впиши BOT_TOKEN
.venv/bin/python main.py
```

Картинки уже лежат в `images/`. Если добавишь упражнения в каталог — докачай картинки:

```bash
.venv/bin/python -m scripts.download_images
```

## Как устроено

- **/start** → раздел (Мужчина / Девушка) → главная с днями активной программы. У каждого раздела свои шаблоны и тексты.
- **Программы**: у пользователя их может быть несколько, «🔀 Мои программы» — переключение одним нажатием.
  Новая программа — с нуля (название → день → упражнения кнопками) или из шаблона.
- **Тренировка**: день → план → «▶️ Начать» → упражнения по одному с картинкой:
  «✅ Выполнено» (сам переходит дальше), «⏭ Пропустить», номера — прыжок к любому. В конце — похвала и статистика.
  Незаконченная тренировка сохраняется в БД — можно продолжить после перезапуска.
  Прямо в тренировке: «🔄 Заменить это» и «🎲 Заменить всё» — замены только на сегодня, программа не меняется.
- **Выбор упражнений**: часть тела → конкретная мышца (например, Ноги → Икры, Плечи → Задняя дельта) → упражнения.
- **Редактор**: подходы ➖➕, повторения пресетами, замена, порядок, удаление, «📝 Вставить списком».

## Новый дизайн (HTML-виджеты)

Весь интерфейс рисуется прямо в сообщении через `sendWidget` (Bot API 10.4, ноябрь 2026).
aiogram этих методов пока не знает, поэтому они описаны в `widgets/api.py`, а нажатия ловит мидлварь в `handlers/widget.py`.

- **Главная и тренировка** — отдельные виджеты (`home_html`, `workout_html` в `widgets/render.py`).
- **Все остальные экраны** (программы, редакторы, выбор мышц, настройка упражнения) — один универсальный виджет
  (`menu_html`): любой экран «текст + кнопки» из `screens.py` автоматически превращается в него (`screen_view`).
  Нажатие в нём приходит как обычный callback в те же хендлеры, поэтому новый экран не требует отдельного кода.
- Экран меняется на месте, если помещается в ответ (до 1 КБ); в длинных списках шлются только изменившиеся кнопки;
  иначе экран приходит новым сообщением, а старое удаляется.
- Лимиты Telegram: HTML ≤ 4096 байт после сжатия, высота ≤ 600 px, без прокрутки, внешних картинок и полей ввода.
  Поэтому длинные списки листаются по страницам, фото упражнения приходит отдельным сообщением,
  а названия вводятся обычным сообщением в чат.
- Если виджет не отправился, бот сам показывает обычный экран с кнопками. `/classic` — выключить виджеты, `/widgets` — включить.

## Структура

| Файл | Что внутри |
|---|---|
| `main.py` | запуск бота |
| `data/exercises.py` | каталог упражнений: название, группа мышц, картинка, подсказка по технике. Замены = та же группа мышц |
| `data/templates.py` | шаблоны программ, пресеты названий дней и повторений, готовые разделы |
| `db.py` | SQLite: пользователи, программы, дни, упражнения, текущая тренировка, журнал |
| `screens.py` | все экраны (текст + кнопки + картинка) |
| `keyboards.py` | inline-клавиатуры и callback data |
| `ui.py` | отрисовка: редактирование сообщения, текст ↔ фото |
| `handlers/menu.py` | /start, раздел, главная, программы |
| `handlers/editor.py` | дни и упражнения |
| `handlers/workout.py` | режим тренировки (обычные кнопки) |
| `handlers/widget.py` | нажатия внутри виджетов |
| `widgets/` | HTML-виджеты и методы API для них |
| `workout_service.py`, `workout_logic.py` | логика тренировки, общая для кнопок и виджетов |

## Как расширять

- **Новое упражнение**: строка в `_RAW` в `data/exercises.py` (ключ, название, группа, картинка, техника). `image` — id из
  [free-exercise-db](https://github.com/yuhonas/free-exercise-db/tree/main/exercises) (или `None`).
  Своя картинка: положи `images/<id>.jpg` и укажи этот id.
- **Новый шаблон**: добавь `Template` в `TEMPLATES` — кнопка появится сама.
- **Мышцы**: `BODY_PARTS` в `data/exercises.py` — часть тела → мышцы → группы замен.
- **Шаблон для раздела**: `sections=frozenset({"female"})` у `Template`.
